============================================================
              OpsDesk - Read Me First (Pehle Yeh Padho)
============================================================

1. Pehle pura folder unzip karo:
   Zip file par Right-Click karo -> 'Extract All' (Sab Extract Karein).
2. '1 START OpsDesk.bat' par double-click karo:
   Server start hoga aur browser me app open hogi: http://127.0.0.1:4173/
3. Login screen par 1-click Demo Persona Selector hai:
   Kisi bhi role (Lead, Agent, Escalation Manager, Requester) par click karke login kar sakte ho. Password: Demo@123
4. LIVE PUBLIC LINK chahie ho toh:
   '3 SHARE PUBLIC LINK.bat' par double-click karo. Ek live public HTTPS link (trycloudflare.com) generate hokar browser me khul jayegi jise phone ya judges ko de sakte ho.
5. Kaam khatam hone par:
   '2 STOP OpsDesk.bat' par double-click karo.

Windows SmartScreen blue popup dikhaye toh:
- 'More info' par click karo, fir 'Run anyway' par click karo.
